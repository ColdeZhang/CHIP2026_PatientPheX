# 原文证据生成与独立HPO规范化

目标是增加可信的患者–表型关系，突破固定候选覆盖，同时保留强基线已有结果。生成器只复制目标患者相关的原文单位ID与短quote，不生成HPO编号；独立规范化器使用公开HPO及当前训练折资源。

当前实验 [GG-20261024-001](experiments/GG-20261024-001.md) 从F2+F3 train32开始，以完整F1的强全文N结果 `.676546354662594` 为主参照。原dev≥.8仍是最终目标，本内部对照不替代它；无新官方上传/查分。

数据只标注患者–HPO关系，没有人工患者–证据span对应。quote训练目标属于弱监督，须报告可构建覆盖、歧义及排除；不能把原文存在当作患者归属证明。详见[研究笔记](NOTES.md)、[台账](WORKLOG.md)、[冻结来源](evidence/initial-sources.json)。
