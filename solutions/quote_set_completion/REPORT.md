# 条件表型集合补全：仅 CPU 准备

建议只保留一个候选：**训练模型在看到患者全文和已报告表型词面后，输出剩余表型词面**。它学习条件补全，不再独立生成两份完整答案后取交集。此处只有训练侧供给与长度证据，没有模型训练、held 质量或 GPU 作业。实际计划为 [proposal.json](proposal.json)，源码/来源与结果为 [readiness.json](evidence/readiness.json)。

## 为什么选它

当前 G 开放 quote 机制曾在两折提供有效新关系；固定双采样虽然 F1 正，但 F0 新增 13 条仅 2 TP，已关闭。这个结果只否定既定共识配方；它不能说明重新生成相同分布能补召回。补全任务把“已经报告什么”作为输入，提供不同的学习信号，仍保留全文、所有患者和独立 HPO 规范化。

候选比较与实际查重：

| 候选 | 已核边界 | 本次决定 |
|---|---|---|
| 普通 Task1+Task2 联合监督 | PCS/PCL 源已实际 `NER_loss + bag_loss`；GLiNER2.5 联合 schema 亦已跑过 | 不把泛称多任务当新机制 |
| 教师伪标注/一致性训练 | 已有模型共享错误；双采样 F0 交集 2TP/11FP。尚无更强、折内独立教师或新无标签域供给证据 | 暂不优先；不声称整族无效 |
| 患者多问法/再次完整采样 | patient-first、逆序、闭集及开放采样已有具体终点 | 不只换 prompt 名称再开同分布推断 |
| 条件残余集合去噪 | 已核 G 原源是全文→完整 quote 集；采样源也是同输入重抽。query-slot 是逐候选判别，DPO 是正确/患者交换答案偏好，均不以已报告集合为条件监督遗漏集合 | 保留一个可证伪初版 |

查重范围是 main H59/MAP、当前拥有者实现及原三路线研究源码，准确 SHA 在证据中；没有把有限搜索说成所有未索引文件均不存在此机制。

## 成熟方法依据与限制

四个公开摘要均已实际 HTTP 200 缓存，来源身份见 [public-sources.json](public-sources.json)。

- [BART](https://arxiv.org/abs/1910.13461) 明确定义破坏输入再学习重建；这里借用有监督去噪思想，破坏的是训练答案集合，不复现 BART 架构。
- [Levenshtein Transformer](https://arxiv.org/abs/1905.11006) 训练插入/删除以实现条件序列精炼；这里仅借用插入式补全目标，仍用已验 Qwen 原生自回归路径，不另造编辑模型。
- [Self-Refine](https://arxiv.org/abs/2303.17651) 支持反馈条件下多阶段生成值得检验，但其无需训练、自反馈流程与本方案不同，公开增益不能外推本赛。
- [Large Language Models Cannot Self-Correct Reasoning Yet](https://arxiv.org/abs/2310.01798) 给出无外部反馈自纠错可能退化的反证。因此不把一句“请补充”当可靠方案，先使用训练标签构造明确补全目标，同时承认推断时没有真值反馈。

## 真实 train-only 供给

只读取原严格 train32 的 G 弱词面目标，原始训练 SHA `38c353ea…`，32 文献/87 患者，未打开 F0/F1 输入或 gold，更未读 originaldev 标签。CPU 唯一 3.613 秒完成，manifest `5210e0f3…`。

对每个患者，把原目标三元组按 `SHA256(20261024|row_id|triple)` 排序并交替分为 A/B；构造 `(known=A,target=B)` 与 `(known=B,target=A)` 两行，列表内部仍按原文顺序。两个集合不交且并集精确等于原目标，每个原 quote 在两行中恰监督一次；输入 known 部分全 mask，答案加 EOS 才监督。没有丢患者、截全文或添加新标签。

| 项目 | 实测 |
|---|---:|
| 训练患者 / 新训练行 | 87 / 174 |
| 原代表性 quote / 残余监督 quote 总数 | 801 / 801 |
| 空 known / 空 remaining 行 | 25 / 25 |
| 完整输入＋答案 tokens | 920,222 |
| 最长完整序列 / 最大监督 tokens | 9,307 / 307 |
| 监督 tokens 总数 | 12,145 |

保留原标签限制：814 个有效原子关系被 801 个代表词面覆盖；4 个患者目标涉及原无效/不完整标签，170 次词面选择有其他患者更近。它们仍是确定关系标签下的弱词面选择，不是人工患者证据。供给计数不能证明训练模型漏召回，也不等于预计可新增的 TP。

## 固定首版与最小证伪

拟从原 d52 rank16 G32 适配器开始，fresh AdamW，以固定 LR `1e-5` 训练新 174 行一轮，累积 8、22 次更新、尾 6、warmup 2。标准 indexed CE 数学保持，最终 checkpoint 固定；新目标、继续训练与 LR 一起构成这项候选，不能声称只改变一个数值变量。原 d52、原输出和优化器状态不改。

推断只复用原 G32 greedy F1 全 39 条的合法且原固定 normalizer 接受的 quote，作为该患者 known 集合；按原文位置排序、精确 tuple 去重，不用金标或置信阈值挑选。新模型对全部 39 患者各生成一次残余集合，native nonthinking greedy1600、原 strict parser 和 b59/train32/public41099 规范化不改。完整 cap/非 EOS/解析失败整行弃答，不迭代追问。

唯一质量端点预定 `B4 ∪ 全部补全关系`，B4 F1 `.701325377212`/预测 `5ad5cfe3…`。原实体、患者、关系和其他字节保留，完整预测冻结后新 1v2/旧0；零新增则 byteexact/0v2。总 Score 严格提高才同权重固定 F0，双折正才讨论 full64；micro/macro 完整披露。不是按患者 oracle，也不另外评训练后模型的独立全答案、不同补全次数或阈值。

主要风险是 **训练 known 为正确子集，部署 known 含假阳性、同义词及可能已完整的集合**。现有两互补视图对于多表型患者没有“全部已报告→空剩余”监督，25 空目标均来自原空/单目标患者；这一盲点先披露，不在看到 held 结果后加样本或改停止规则。若初版负，关闭该固定配方并保留原因。

## 可复用资源与成本

继续复用已验 9B 基座、d52、原 indexed head、单 owner 时钟、raw-first 与 SHM→.100 持久 ACK 协议，不构建第三套训练循环。新 warm-start adapter 接口和新完整字符串仍需实际 HF native CPU 对照；本地 tokenizer/mask 通过不替代它们。

原 G32 87×2 共 174 行/903,344 tokens，A100 实际训练 2039.028 秒；新 174 行/920,222 tokens 是 1.0187 倍上下文量，监督量较少。这仅是成本代理，不能保证 A800 或 warm-start 实耗。

若后续获准，建议单 CPU120+5 → 真实新形状/已建 Adam 压力240+30 → 完整单轮及最终完整 state ACK3600+30 → 全39推断1800+30 → 必要 Sap180+30。当前只有 CPU 准备授权，以上均未启动；真实 probe 如不满足预算/显存则报告，不截样本或临时换后端。
