# 方法与边界

强 Task1 文档概念只能支持“本文出现这个概念”，不能支持“属于这个患者”。geometry 的既有诊断以患者归属错误为主，所以文档门可能不能解决其主要误差；本次仍按预锁公式完成一次低成本反证。

直接调用冻结公共 v2 的 `associations` 与 `document_concepts(all,text)`：合法纯 HPO 复合值按原规则拆分；单 HPO 只同 ID 匹配，不扩父子、alt-ID 或同义词。其他关系值只与 `unlinked_text` 的完整原始字符串匹配。含分号的 NIL 和混合字符串不得假装 HPO 复合项。`NO` 实体不能提供支持。

保留所有 B 对象和原关系列表，新增只追加。缺文档、患者键变化、未知输入 SHA、格式问题都应报错；无增量直接复制 B 字节并零评分。原 geometry 单臂/旧 union、原 PCS 8/24 结论均不改变。

参考已有 `four_source_fusion/run.py` 的固定公式、冻结与单终点流程；祖先及公共评测器的准确 SHA 在计划中。没有新的学习组件或权重，复用已经完成的隔离审查。
