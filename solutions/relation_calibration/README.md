# 三源关系校准

目标：检验三个新关系信号的不同可靠性是否能超过固定二源一致融合。唯一实验见 [E-20261024-RELCAL-001](experiments/E-20261024-RELCAL-001.md)，恢复状态见 [WORKLOG](WORKLOG.md)。

训练集为 F1 全16篇/39患者，标签明确用于元模型训练；留出集为 F0 全16篇/47患者。只使用 grounded 全关系、两个采样全关系的交集、Qwen3 全关系的三个二元指示。F1 强基线 B1 及其增量不参与行选择、特征或阈值。

`prepare.py` 只核来源和纯输入并冻结计划；`run_fit_once.py` 以30秒+TERM5秒运行唯一 `fit_once.py`。`assemble_F0.py` 只在完整来源绑定后应用冻结参数，保留 B0 的全部关系、实体与非关系原字节；不含金标读取或评分入口。F0 两完整端点与主线程固定2of3共同冻结后，才能绑定唯一评价。

全量关系、训练标签、pickle和日志位于仓库外 `round2-20261023/research/relation-calibration-20261024/`，Git 保存源码、参数与摘要。
