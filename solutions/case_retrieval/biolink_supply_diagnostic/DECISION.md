# BioLink 新候选供给：当前不追加学习融合

2026-10-24，已知内部 F0 的一次候选供给诊断。目标是判断旧 BioLinkBERT-large NER＋Sap 是否为强三 public 原始候选池提供足够新信息；没有运行预测器、拟合、v2 或阈值扫描，也没有读取原 dev。

来源核验覆盖原 NER、别名/字符链接、关系 LR、Sap 冻结编码器及词库、强池递归来源。两链均使用相同 train48，排除全部 F0 16篇；复用原来源审计与当前 LGB pool manifest。统计只使用已保存的 NER≥.55、Sap≥.65替换 ID 后的1117实体，并非未阈值化原始跨度。

强池有14880个支持 ID 单位，已覆盖1134个合法正向 gold 单位中的982个。新增仅补足剩余152个中的1个。133个新单位中132个没有严格支持 ID gold 匹配，其中18个落在已标注正向跨度、114个没有对应正向跨度；这是 **候选与标注未匹配数**，不是选择器的实际假阳性。另有7个此前未覆盖的 NIL 通配跨度，只说明边界供给，不证明 HPO ID 正确，未加进严格 ID 命中数。

**决定：当前不追加严格 OOF 学习融合。** 保存候选的互补证据很弱，且该 train48 模型不能为其自身训练48提供 OOF 特征，需要额外训练成本。本诊断不证明未保存的低置信度 BioLink 原始跨度无用，也不预测可能达到的 Score。F0 已多次用于研发，本次不是盲测，不从具体错例定规则。
