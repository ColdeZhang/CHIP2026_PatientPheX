# 已有训练侧证据：关系提升的下一步

目标是找出当前关系错误中哪些能由关系方法修复，而不是默认再训模型。只读取固定F1 16篇/39患者的既有候选、gold和freshSFT32的80条OOF输出；该模型训练于F2+F3，未见F1。F1属于meta训练范围，以下不是新验证Score，更不是原dev结果。CPU诊断，无新GPU/推断/阈值搜索。

## 可精确分开的缺口

| 分母/错误类别 | 数量 | 可支持的结论 |
|---|---:|---|
| canonical gold关系 | 520 | 本诊断用冻结HPO alt映射 |
| 候选池覆盖的gold | 366 | 现池关系召回上限70.38%；原两树raw监督365不改写 |
| SFT TP / FP / FN | 311 / 72 / 209 | 既有离散输出统计，不是v2 Score |
| FN：候选完全缺失 | 154 | 占FN73.68%，关系选择器无法补回 |
| FN：候选CID输出空列表 | 31 | 可称空答案漏选，不能称已测低置信度 |
| FN：CID非空却未列目标患者 | 24 | 其中7项所选其他患者全正确；不能全叫错误身份归属 |
| FP：概念属于别的指定gold患者 | 28 | 是按gold的跨患者错误，不是已证明的共指原因 |
| FP：概念不属于任何指定gold患者 | 44 | 可能涉及概念/背景/极性等，不能仅凭集合确认具体原因 |

154个缺候选的关系键中，153有标注实体证据，但只有7有预测候选exact span、45有任意跨度重叠。这是关系键数量（含同概念多患者），不是缺实体去重数量；单修HPO alias或重链已有精确跨度不能覆盖大部分缺口。

## 身份与截断只能给结构代理

55个候选内FN中，21在实际保留证据里有目标患者标记；31在所有原±500字符证据窗里都没有；仅3是top4选择把现有目标标记全部丢掉。55个全都有全局患者标记，实际输入/输出token截断均0。缺局部标记并不等于模型必然失败：311个TP中111个同样没有任一局部目标标记。因而不能把55全归因于身份信息，也不能凭这3项证明“扩大上下文”会改善。

既有CE训练侧48篇审计也显示969个正候选中579个所有±220窗均无目标标记，但top3/384没有把原本存在的目标标记全部丢光。其身份桥接配对已负；本次新的SFT输入是±500/top4/global anchors，两个机制与分母不得混用。全文8B及全文9B旧控制也没有稳定收益。

## 最多两项建议

1. **先把候选召回缺口交给实体线处理。** 在这批固定训练侧样本里，154个缺候选远多于55个关系漏选。优先以已测缺口划分跨度检出与链接问题、建立低噪声候选补全控制；不能为修154缺口而给关系模型加epoch。这是下一工作优先级，不是声称现成扩池必然增分，新增实体精度仍须独立控制。
2. **关系线仅保留一次有限决策排序的可辨别检验。** 31个空CID FN、24个多患者漏选及28个跨患者FP，说明只比较空/非空或单患者不足。现有raw无logprobs，原12训练拟合F1 .884不支持直接加epoch。可研究对现有候选的有限患者集合做teacher-forced条件概率检查，明确前序CID上下文、空/非空长度归一化和多患者表达；先在训练侧核概率确实有可用排序及真实成本，再决定是否构建严格折内融合。没有实际NLL对照历史，原proposal可选NLL从未执行；这也不等于已获得可调阈值。该项由只读模型研究补具体设计，当前没有GPU授权或自动执行。

当前单meta-fold融合选择器已经关闭：SFT四事实相对共同LR+上下文有+.010284增量，但仍输直接SFT48与规则。上述建议不能将该负结案改写为成功。
