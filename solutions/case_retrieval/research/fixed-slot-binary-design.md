# 固定问题槽二元目标：CPU 设计与唯一机制控制

推荐只验证 **fresh 固定问题槽分类**，不扩候选或上下文。当前 F1 的最大已知缺口仍是 canonical 154 个缺候选关系，公开固定并集最多覆盖其中 103；本控制只能检验已有候选内的关系决策，不能补剩余 51 个缺候选项。

## 为什么与旧负控制不同

已完成的 530 子集条件似然把原 JSON SFT 的生成分数重归一，仍依赖旧 greedy 前序；固定 .5 从 34TP/7FP/4FN 变为 24TP/21FP/14FN，已关闭。新方案改变训练目标：证据之后仅串 `Question C000 / P1:\n` 等固定问题，输入永不含任何真值或预测答案；每个问题末 token 的 hidden state 经原有冻结 LM head 的 `0`、`1` 两列分类。多患者可以同时为 1，也可全部为 0，无集合枚举和 CID 复制目标。这不是再次把硬四事实入 HGB。

实际 CPU 完整串编码通过：124 行、32 文献、880 CID、2,506 标签（594 正/1,912 负）；翻转全部训练标签后 input IDs 和槽位逐项不变。F1 80 行/587 CID/1,557 对仅构建无标签输入。原 user 证据逐字节不变，训练标签可完整还原原 CID→患者列表。396 个空 CID、78 个多患者 CID 均可表达。独立重分词审查 `f8e7c8ce` 通过。

读取位置为问题末分隔符的 **当前位置**，不减 1、不传 native `labels`。调用原 PEFT `forward(logits_to_keep=slot_positions)`，再取 `.logits[0, :, [token0, token1]]` 的等价 `index_select`，用 float32 二类 CE。实际 meta 模型层级核得冻结 `Linear[248320,4096]`，既有 43,278,336 个 LoRA 参数可训，无新 head；CPU 未证明真实 GPU 数值或梯度，须短 probe。

## 唯一固定训练配方与判断边界

使用同公开 9B **fresh base**、同 seed20261023、r16/alpha32/dropout.05、lr1e-4/AdamW wd.01/maxnorm1/BF16/SDPA。不用已训 SFT32 初始化，避免把累计多训练两轮和旧 JSON 目标预热混作新目标收益。保持原 124 行及严格 F2/F3 双方向候选来源；2 epochs、32 optimizer updates、2 warmup、microbatch1/accum8，最后 4 行组除以 4。每行所有槽的无权重二类 CE 取均值，再按原累积组取均值；不声称是全体 pair 均等加权，不改类权重。

固定阈值 .5、唯一最终 epoch002。与同源旧 SFT32→F1 比较，保留原实体和 None 装配契约，不混用 SFT48/另一折作目标对照。80 行全部概率及完整预测先冻结，再一次 F1 公共 v2/格式、同候选 TP/FP/FN/Brier/AUC、旧 FN 回收和新损失；不扫描阈值/温度、不读原 dev，不现在扩公开训练候选。F1 已参与开发，不称新盲测。

原 SFT32 实测 1149.46 秒；按真实 token 比例粗估新两轮 1210.83 秒、F1 单 forward 总约 55.87 秒，均不是实测承诺。root 已授权一次 A800 GPU2 `180s + TERM15` probe：实际短行 880 token/3 槽比较原生 full logits 与选位两列；最长 6777/112 槽做有限 loss、三家族 LoRA 梯度及非零 lr 参数变更，验证 LM head 冻结，随后丢弃状态。若实测成本/显存支持，再另一次 fresh 固定训练 `1800s + TERM30`；推断独立 `≤300s + TERM30`。磁盘实查约 890 MB，拟仅保存最终完整 adapter+Adam/scheduler/RNG（约 520 MB），不保存中间大检查点或自动续跑。

源码、全部 CPU 统计和授权 probe 计划见 [小证据](../evidence/round2/fixed-slot-binary-plan.json)。原 CPU 两次工程失败（缺 helper、PEFT config 应传目录）与紧凑比较均在外存独立目录保留，没有 GPU 或质量运行。

## 预写单次 CPU 集合解码对照

固定 .5 主终点结束后，仅对同一 adapter 的概率按患者计算独立 Bernoulli 期望 F1，选择包含空集的 top-k；精确同分选更小 k，概率同分保持原 CID 顺序。实际 1557 CID×patient 对与 literal-v2 关系单元一一对应，compound 扩展/重复冲突均为 0；3 个原文字串原样保留。源码复用研究的 36 组/1059 子集合成契约，新增原评测函数的 compound/mixed-text 合成装配检查通过。整次 CPU ≤30 秒，无 cut/温度扫描；完整预测先冻结再唯一评测。保留标准预写为 Δ(micF1+macF1)>0 且 ΔmacF1≥0，否则关闭。独立性和校准只是模型假设，不保证全量缺失真值或联合评分最优。[计划与来源](../evidence/round2/fixed-slot-expected-f1-plan.json)。

后续资源只读核查：A800 最终约 520 MB 状态保存后不够第二套检查点；A100 GPU2 在 22:50:57Z 当时为空且盘余 66.9 GB，已有持久基座 15 文件大小匹配。只检查 CPU 包导入/文件大小，没有重哈希权重或初始化 CUDA；torch2.6 与本轮2.7.1不同，如将来获准迁移须重新做实际数值接口检查。

## 结论

实际fresh目标提升同模板base，但固定.5 .630248和唯一expected-F1 .648033都低于同折旧JSON SFT32 .660942。expected自家增益成立，不能外推训练目标或全64收益；当前配置关闭，不扫描阈值、追加epoch或迁原dev。独立重放包括不同DP的期望F1所有k，详见[完整结果](../evidence/round2/fixed-slot-binary-result.json)。
