# Bioformer 训练侧 Task1 漏检机制

本任务只诊断已经冻结的四折全候选概率与训练侧选定 `.3` 预测，不做新 fit、阈值选择、原 dev 评测或 GPU。目标是判断下一步应优先补候选，还是改善已有候选的选择；不是制造新的 oracle 预测。

固定 evaluator v2 的 `all/text` 口径，复合 HPO 按原字符串拆分，不统一 gold 的 canonical ID。先逐跨度消耗准确 ID，再让剩余未链接 `-1` 消耗一个剩余预测；混合 linked/NIL 标注中，同跨度已有候选不自动代表 NIL 可覆盖。文档级未链接概念使用原样文字，不能由 linked ID 替代。

将每个现有 FN 唯一归入：正确候选缺失（再分同跨度错误 ID、仅重叠、无重叠）、支持候选全部低于 `.3`、候选达到 `.3` 但被既有 greedy 冲突拒绝。NIL 的同跨度供给已被 linked 匹配耗尽单列。文档级另分概念缺失与候选全部被拒绝。候选并集的供给只是诊断，不能当作非重叠解码器可达到的召回上限。

[冻结计划](../evidence/round2/bioformer-task1-fn-plan.json)逐项绑定 train64、四份概率/拟合 manifest/完整预测、既有结果/审查及实际 evaluator 源码。CPU 硬限 120 秒；只在内存重建相同 `.3` greedy trace 来定位 blocker，并与原预测完全相等，再将计数与原 `.3` 各折/pooled 计数核齐。全量候选、标签和预测不复制到 Git；仅保存脚本、聚合计数与恢复入口。此诊断是已有开发数据上的事后分析，不能称新独立验证。

实际入口 `diagnose_bioformer_task1_fn.py`（SHA `daa8420c…`）已于 21:43:52Z 运行，程序 0.546 秒、外层 0.590 秒、rc0。20 个引用实际 SHA/大小匹配，四折逐个实体等于原冻结预测；每折和 pooled 的 TP/FP/FN 与既有 `.3` 曲线完全相等。未写任何新预测，未读 originaldev。小合成例覆盖复合 ID、未链接精确匹配/剩余匹配、literal 文档概念；真实数据 mixed linked/NIL 同跨度为 0。

## 结果

分母为 64 篇、61,781 个候选（61,253 种跨度）、4,315 条已选实体记录；gold 有 4,828 个去重 mention 原子，其中 linked 4,730、unlinked 98。原结果 mention TP/FP/FN = 3,493/825/1,335；document = 1,803/273/648，gold 文档概念 2,451。复合 ID 使原子数与实体行数不同。

| Mention FN 机制 | 数量 | 全部 FN 比例 |
|---|---:|---:|
| 同跨度存在候选，但缺正确原始 ID | 298 | 22.32% |
| 无可匹配的完整跨度，只有重叠跨度 | 269 | 20.15% |
| 没有任何重叠跨度 | 115 | 8.61% |
| 支持候选存在，但全部低于 `.3` | 544 | 40.75% |
| 支持候选达到 `.3`，被既有 greedy 拒绝 | 109 | 8.16% |

前三类合计 682（51.09%），后两类 653（48.91%）。greedy 的 109 项中，以最高优先级支持候选的实际 blocker 归类：106 为不同边界重叠、3 为同跨度竞争 ID。NIL mention TP5/FN93；其 FN 为 47 个跨度缺失、46 个已有 span 候选低于 cut，未把 linked 候选强制变成 `-1`。

| Fold | Mention FN | 池支持缺失 | 全低分 | Greedy 冲突 |
|---|---:|---:|---:|---:|
| 0 | 327 | 186 | 121 | 20 |
| 1 | 366 | 158 | 164 | 44 |
| 2 | 326 | 166 | 134 | 26 |
| 3 | 316 | 172 | 125 | 19 |

文档级 648 个 FN 中，263（40.59%）在候选池没有该 evaluator 概念，319（49.23%）全部低分，66（10.19%）达到 cut 但全部被 greedy 拒绝。263 个池缺失包括 88 个原样未链接文字概念；linked 同文字不能满足该文档指标。

结论：mention 漏检略过半来自候选供给，补充**正确原始 ID 和完整边界**有明确空间；近半 mention 和约六成 doc 漏检仍由选择阶段产生，不能把后续工作只归于候选扩充。现有预测仍有 825 个 mention FP，FN 数量本身不证明放低阈值会改善质量。109 个 greedy 冲突只是较小部分，不能据此立即换解码器。298 个同跨度原始 ID 不符尚未细分 alt ID，不冒称全是实际语义链接错误；本任务不做基于 gold 的 ID 补丁。
