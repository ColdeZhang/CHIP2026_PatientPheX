# 少标签临床 NER 的受控增强：只读研究提案

2026-10-23；状态：**研究完成，未实现增强、未生成训练样本、未启动 GPU 或下载权重**。来源与训练内可行性计数见[小证据](../evidence/round2/ner-augmentation-research.json)。

## 结论与真实目标

目标是补足未识别的原文跨度，最终改善冻结公共 v2 的完整 Score。既有 train48 三 nested 诊断中，1364 个 FN 有 908 个无重叠、411 个边界/嵌套问题，说明单纯改善已选跨度的 ID 链接覆盖有限；这不是 GLiNER 新增跨度的错误分布，不能直接估计增强收益。

**没有找到证据强于当前 large GLiNER 的低成本替代方案。** 保留 A 为一次可否证的后备控制；B 工程改动更大、领域证据更弱，优先级更低。等待当前固定训练结果，不因有空闲算力自动追加实验。本文的两个方法均未在本项目实测，不宣称能达到 .8。

主线程随后选择先做 CPU 准备：保留1150个原窗，每窗最多追加1个变体；真实tokenizer/collator逐行审计后再定GPU预算。这与下文最初提出的等步数在线替换不同，正式计划须明确数据量与更新步数同时增加。当前尚未生成样本或授权正式训练。

## A：同一 HPO 的完整实体同义词替换

成熟依据是 Dai、Adel，COLING 2020，[An Analysis of Simple Data Augmentation for Named Entity Recognition](https://aclanthology.org/2020.coling-main.343/)，§3 的 mention replacement（MR）和 synonym replacement（SR）。论文 MR 用训练集中同类型的完整 mention 替换，SR 用 WordNet；**本提案改为同一 canonical HPO 的 name/EXACT synonym，是更严格的项目适配，并非论文原样复现**。

论文在 i2b2 的 SciBERT+CRF 上，50 个正例句时 MR 的 span F1 为 35.1→40.1，SR 为 35.1→42.3；500 句 MR 70.2→70.8，完整训练集 MR 87.8→87.8。五次运行且原文对增强概率/数量调参；收益主要出现在极小数据量，不能把 +5 F1 外推到本项目 1150 窗或 GLiNER。它支持“词面变化可帮助少标签 NER”的假设，不证明本项目有效。

**机制与边界**：将官方 train32 已标肯定跨度替换成同概念的另一词面，保留真实上下文及 phenotype 标签，增加“语境—词面”配对。可能改善词面泛化和完整实体边界；不会提供训练标签之外的新 HPO 概念、真实新病例或患者归属证据，也可能产生语法不自然、嵌套标注不完整的问题。

最小可执行控制，仅在主线程后续选择执行时：

1. 只使用既有 nested train32 和指定 HPO 2026-06-23；限定已能映射到 GLiNER 的肯定、单 canonical、无重叠完整实体。排除 NO、NIL、复合 ID、alt ID 和多概念歧义词面；候选来自同 ID 的 name/EXACT synonym，且规范化后与原词面不同。先只读训练样本检查语义/词形适配，失败样本跳过，不从验证错例选替换词。
2. 固定种子 20261023、每个合格窗口以 .5 概率最多替换一个完整 mention；按窗口/epoch 确定随机状态。保持每轮 1150 行、batch4、fresh medium-v2 固定 10ep/2880 steps，不同时改 loss、学习率、阈值或链接器。原样本曝光比例随增强变化，明确记录；不通过翻倍数据额外增加优化步数。
3. 长度变化后重算该窗口全部 token/字符跨度和 NO 索引，核对每个正跨度文本与标签、真实 tokenizer 输入≤384、实体宽≤12、实际 collator 的 span mask/labels。只使用临时合成坐标，不能冒充原文预测坐标；保留来源文献/原跨度。任何断言失败停止。仍不能把合成标签称为新增人工金标。
4. 完整训练仅看固定 epoch10。用同一 nested16 输入、固定 Sap/CRF 装配及 evaluator v2 比较既有 **.653745027**，同时报告 mention/doc/两关系分项、实体增删 TP/FP/FN、无重叠/边界错误变化与训练成本。该 nested16 已用于开发，不是新盲测；原 dev gold 不参与本控制。
5. 仅当完整 Score 超过基线且格式/来源审核通过，才考虑另一训练内折复验；否则关闭本配方，不扫替换概率、词典、epoch、loss 或阈值来补救。单折小幅提高也不直接宣布普遍收益或迁移原 dev。

CPU 预筛（**未构造替换文本**）：32 篇、1150 窗、2275 条肯定标注；其中 2236 已在现有窗口表示，2163 为单 canonical，2143 不与其他跨度重叠，2010 条有另一唯一 name/EXACT 词面，去重后 **2009 个跨度、408 个窗口**。这是机会数量，不是预计修复的 FN；只用了正则分词≤12 的粗筛，尚未过真实 tokenizer/collator。现有同规模 medium10 的 A800 训练实测 519.035 秒/2880 步，供预算参考；增强后的实际用时未知，若重跑配对基线成本约再增加一个同规模训练，不能当作已测新成本。

许可与标签：论文 CC BY 4.0；未核验可复用的作者实现及其代码许可，可自行实现短策略并引用方法。只阅读论文，不取其 i2b2 人工临床标签或权重。增强材料仅为本赛训练折和官方允许 HPO，沿用现有已核验 Apache-2.0 GLiNER 基座，不引入外部人工表型数据。

## B：同一病历的相邻段落上下文（备选）

[FLERT，Schweter、Akbik，arXiv:2011.06993v2](https://arxiv.org/abs/2011.06993v2) 给目标句附左右各 64 subtokens，目标 token 才参与标注，遵守文档边界。XLM-R-large 的 CoNLL 英语测试 F1 92.79→93.64，其他四组语言也提高；**不是临床实验，也不是 GLiNER 的证据**。可参考 FLAIR 固定 [d4ea3777 的 transformer.py](https://github.com/flairNLP/flair/blob/d4ea3777998ba67bfbe6b6b8359e024dcf673c3e/flair/embeddings/transformer.py) 的上下文装配，代码 MIT；现代实现不等同论文原始版本。

当前 GLiNER 准备/推理按 passage 独立切窗，长段已有 12-word overlap，短段看不到相邻段落。可保留原目标窗，只有剩余预算时附同篇相邻原文左右最多各 64 subtokens；总预算仍384，推理只输出目标窗跨度。**上下文及跨目标边界的 span 必须从 loss/解码中屏蔽**，不能把有表型的上下文当负例；保留原文全局坐标映射，分隔符不得生成预测坐标。它可能帮助短段语境和歧义，不能增加真实词面覆盖，标题/讨论上下文也可能有害。

训练32 中 1028 窗≤256 tokens 且所在文档有其他段落，其中335窗有正跨度，只说明潜在空间。没有判定相邻段落的临床相关性。若执行，先做所有拼接/label/target mask 的 CPU 核验，再独立于 A 用同基座、同10ep/2880步和同完整 Score 验收；最大长度相同但平均 token 增多，实际吞吐/显存需重新量测。需要更改 collator 与推理解码，成本和风险高于 A，目前不建议安排。材料只用当前输入文档，不引入新标签/外部数据；不照搬论文的 train+dev 设定。

## 与已试机制的区别及不建议重复的工作

- **PhenoTagger**：既有 HPO100ep 及真实词面3ep主要做孤立短语/None 分类；已见训练词面拟合很好、原 dev 无实质收益。A 将同义词放入真实已标上下文并训练跨度识别，机制不同，但不是对失败配方“再加轮次”。B 也不同于已有“给定 span-ID 的上下文 CE”和患者关系 CE/MIL。现有实验台账未见实际执行完整实体替换或目标窗附相邻 passage 的 NER 对照。
- **NuNER/GLiNER**：NuNER 的 GPT3.5 自动标注百万 C4 句是通用预训练；当前 GLiNER-v2 已沿用该谱系，再取同模型不能算新增强。重建大规模伪标签既不便宜，也没有本项目比当前基座更好的证据；不生成新 LLM 语料。来源 [NuNER 论文](https://arxiv.org/abs/2402.15343)、[GLiNER 论文](https://aclanthology.org/2024.naacl-long.300/)。
- **损失函数**：GLiNER 论文式3与上层默认均为 BCE（alpha=-1、gamma=0），函数名 focal 不表示默认做 focal；本项目显式 valid-span BCE 已修接口错位。负例数量多不足以证明正梯度被淹没。A/B 都保持现有 loss，不把未验证的 loss 猜测附加到数据实验。
