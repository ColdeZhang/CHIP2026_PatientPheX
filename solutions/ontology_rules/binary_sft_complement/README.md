# 固定二元概率与旧 SFT 决策的互补性预检

目标：判断新 fixed-slot binary32 概率能否在旧 SFT32 正/负两组内部区分真实关系，而非只看整体 AUC。输入为同 F1 冻结80提示、1557 literal pair；两模型均只以 F2+F3 训练。先核原 CID/患者/概率/原始 gold 映射，无 canonical 改写。

只统计每组 ROC AUC、AP、Brier、固定 [0,.1,.25,.5,.75,.9,1] 分位数与既有 .5 的错误交集；不扫阈值、不 fit、不推断、不生成正式预测。CPU ≤60秒。F1已用于开发，该诊断不能证明校准、泛化或融合一定有益；155个候选池外 gold 关系保持单列。

旧 SFT+LR HGB 具有上下文/LR和四SFT事实，不等价于新直接 binary logit 与 SFT hard 两特征。另并行只读核严格来源，若有互补，仅提议F1元训练→F0控制，尚无新训练或推断授权。所有文件独占本目录，检索路线只读。
